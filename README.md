# PENTAPOLIS

Pentapolis combines the visual city-building style of classic titles like SimCity or TheoTown—where every vehicle, construction site, crane, and pedestrian is visible at 60 FPS—with a rigorous, self-contained macro- and micro-economy spanning five interconnected regions, where every single penny is accounted for.

---

## О проекте (GDD v4.1 Canon)

**PENTAPOLIS** — многопользовательский асинхронный 2.5D градостроительный, макроэкономический и геополитический симулятор для **5 мэров на одном изолированном полуострове** (единая плоская сетка `1000 × 1000` тайлов без тумана войны, альбомная ориентация / Landscape PWA).

### Ключевые механики
- **Замкнутая мультивалютная двойная запись (`BigInt`)**: все расчёты ведутся в минорных единицах (`100n` = 1 единица валюты) по 7 балансовым колонкам (`HH, Fc, Fk, T, Banks, CB, World`). На каждом месячном шаге автоматически проверяются **4 железных инварианта** с точностью до **0 копеек (`0n` diff)**.
- **5 суверенных национальных валют + МРЕ (`WCU`)**: свободно плавающие валютные курсы из 16 канонических валют во главе с обязательной в каждом сезоне **Гривной (`₴ UAH`)** (рубль исключён из списка валют; маршрутки исключены из транспортной системы).
- **Двухконтурная собственность и правило 10% / 90%**:
  - **Контур Б (100% казна города)** — добывающие шахты/скважины (`EXT`), электростанции (`ENG`), магистральные трубопроводы, КПП, службы и хабы;
  - **Частно-муниципальные заводы Ур. 2–4 (`10% / 90%`)** — Мэрия вносит от 10% стартового капитала, а частный рынок выкупает оставшиеся 90% при `ROI > ставка кредита`. При отказе рынка стройка переходит в режим *«Замерший кран»* с правом **100% муниципального выкупа (Backstop)**; снос совместного завода возможен только после 100% выкупа акций городом (*Eminent Domain*).
- **Единый полуостров `1000 × 1000` и гибридная сетка `90° / 45°`**:
  - 5 выровненных секторов (~90 000 тайлов суши каждый, `±5%`) в кольце `1 ↔ 2 ↔ 5 ↔ 4 ↔ 3 ↔ 1` вокруг нейтрального **Центрального Ядра Мегапроектов** `(500, 500)`;
  - 5 речных систем (мосты через реки автоматически стоят `3x`), 5 внешних шлюзов (2 северных шоссе и 3 подземных туннеля), 25 месторождений ресурсов;
  - 127 типов зданий, 24 производственные цепочки (с газовым бустом `+40%` выработки), 56 типов транспорта, **140 580** детерминированных визуальных вариаций зданий.

## Архитектура монорепозитория (TypeScript + Bun Workspaces)

```text
PENTAPOLIS/
├── packages/
│   └── shared-sim/        # @pentapolis/shared-sim: детерминированное ядро, парсеры 25 CSV-листов,
│                          # мультивалютный движок RegionalMoneyEngine (BigInt), сетка PeninsulaGrid
├── apps/
│   ├── server/            # @pentapolis/server: авторитативный Bun HTTP + WebSocket сервер + SQLite (WAL)
│   └── client/            # @pentapolis/client: Vite + React 18 + Tailwind + Three.js (2:1 изометрия)
├── tools/

│   └── dev.ts             # Одновременный запуск сервера (:3001) и клиента (:5173)
└── docs/
    ├── design/            # Канонический GDD v4.1 (.docx), таблица баланса (.xlsx), схема и референс
    └── prototypes/        # Исходный прототип макромодели и прогон 36 месяцев
```

## Быстрый старт

Требуется установленный **[Bun](https://bun.sh/)** (`>= 1.1`).

```bash
# Установка зависимостей всех пакетов монорепозитория
bun install

# Запуск авторитативного сервера (http://localhost:3001) и клиента (http://localhost:5173)
bun dev
```

### Проверка качества, тесты и аудит экономики

```bash
# Полная проверка типов TypeScript во всех 3 пакетах
bun run typecheck

# Автотесты (каталоги, 36-месячный аудит 180 матриц 0n, сетка 90°/45°, сервер и SQLite WAL)
bun test

# 36-месячный CLI-аудит 5 суверенных регионов с выводом макро-таблицы
bun run sim:run36

# Перегенерация 25 канонических CSV-листов из docs/design/*.xlsx
bun run export-sheets

# Продакшен-сборка веб-клиента
bun run build
```

## Управление в клиенте

- **ПКМ / СКМ / `Пробел + ЛКМ`** или **`WASD` / Стрелки** — перемещение изометрической камеры по полуострову `1000 × 1000`.
- **Колесо мыши** — плавный зум от стратегической карты всех 5 секторов до уличного масштаба.
- **ЛКМ (протяжка в режиме «Сети 90°/45°»)** — строительство дорог, проспектов, Ж/Д, трубопроводов, ЛЭП и эстакад (`Z = +1`) с автоматической привязкой к углам `0° / 90°` и `45°`.
- **ЛКМ по машине (режим «Осмотр»)** — карточка транспорта (владелец, маршрут, груз, скорость, износ дороги) → кнопка «Досье водителя» открывает досье жителя с бюджетом семьи до копейки и его мыслями.
- **Кнопка «Город»** — советники (градостроитель, финансы/ЦБ, логистика), районы с ценой земли, преступностью, экологией и покрытием службами (+ карта цены земли на зонах), активные ЧП с бригадами в пути, 8 городских указов и авторынок.
- **Кнопка «Транспорт»** — статистика потоков, Дорожная служба (0 / норматив / усиленный), ремонт участка или всех изношенных дорог, выдача лицензий на автобусные маршруты (клик по остановкам TRN-01) и слой «Под землёй» для метро.
- **Клавиша `` ` `` (`~`)** — открытие **Админ-панели / Бог-режима** (`+1 час`, `+1 день`, `+1 месяц`, `+1 год`, смена сектора `S1..S5`, запуск любого из 12 городских ЧП, сброс сектора до `$10M`).

## Спринт 5: живой трафик, износ дорог, автобусы, метро и досье жителей

- **`packages/shared-sim/src/traffic/`** — детерминированная модель трафика:
  - `roadPhysics.ts` — классы дорог из листа 23 (скорость, пропускная способность, деградация под фурами), стадии износа GDD §5.2 (ямы 74–40%, авария <40%), износ по осевой нагрузке из каталога транспорта, Дорожная служба и стоимость ремонта;
  - `roadGraph.ts` — граф сети 90°/45° с узлами на перекрёстках и пересечениях, A*-маршрутизация по времени в пути (с учётом износа и пробок);
  - `trafficModel.ts` — потоки «дом → работа» с часом пик, грузовики «от отправителя» (шахта → завод-потребитель или внешний шлюз), лицензированные автобусы, метро; выборка видимых машин и привязка каждой к реальному жителю;
  - `citizens.ts` — карточка машины и досье жителя (BigInt-бюджет семьи из классов `RegionalMoneyEngine`).
- **Сервер** — тактический тик (каждые 600 игровых секунд) пересчитывает потоки; часовой тик изнашивает дороги по реальной нагрузке; месячный — списывает бюджет Дорожной службы и зачисляет лицензионные сборы автобусных перевозчиков. Новые API: `GET /api/traffic`, `GET /api/vehicle/:id`, `GET /api/citizen/:id`; WS-сообщение `traffic_state`. Команды: `create_bus_route`, `delete_bus_route`, `repair_road`, `update_policy.roadServiceLevel`.
- **Клиент** — `TrafficRenderer.ts` (4 `InstancedMesh`: авто, фуры, автобусы, поезда метро; правостороннее движение 60 FPS), панели `TransportPanel` и `AgentInspectorPanel`, оверлей маршрутов и слой «Под землёй».

## Спринт 4 (доделка): девелоперы и стройматериалы

- `packages/shared-sim/src/construction/developerMarket.ts` — зоны застраиваются по тайлам, застройщики покупают материалы по листу 20 (таблица 5): сначала у своих заводов, затем импорт через стартовый шлюз (лимит, фрахт, ввозная пошлина в казну). Без материала кран замирает.
- Модернизация зданий по времени из листа 22 (24–168 игровых часов), завод работает на старом уровне.

## Спринт 6: районы, службы, ЧП, указы, авторынок, советники

- **`packages/shared-sim/src/city/`**:
  - `cityServices.ts` — цена земли $120–$6 000 за тайл (GDD §6.3): пол из листа 22, бонусы служб и снижение преступности/загрязнения из листа 25 (таблица 6), дым заводов, парки, указ о газификации, метро; 5 уровней районов (таблица 5) задают внешний вид зданий (P/M/R); вместимость станций делится между жителями;
  - `emergencies.ts` — ЧП возникают из реального состояния сектора (нет пожарных, дороги <40%, смог, нет полигона, дефицит энергии, безработица), ближайшая служба выезжает по дорожному графу; без службы ЧП длится втрое дольше и оставляет ущерб;
  - `autoLifecycle.ts` — автосалон → trade-in → б/у → СТО → металлолом (таблица 3): старение по календарю жизни, поломки растут на разбитых дорогах, 1,2 т лома с машины;
  - `advisors.ts` — 3 советника читают состояние сектора и предлагают конкретный рычаг.
- **Сервер**: ежедневный тик (ЧП, авторынок), машины служб видны в трафике и кликабельны (досье пожарного/фельдшера), районы влияют на темп девелоперов ((H/70)², GDD §6.7) и на Индекс Гегемонии.
- **Клиент**: панель «Город» (`CityPanel.tsx`), карта цены земли, цвет маяков ЧП (едут / никто не едет).
